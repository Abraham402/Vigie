# Vigie

Plateforme personnelle de surveillance des marchés (crypto et actions) : probabilités de hausse ou de baisse, actualités analysées, IA analyste, alertes Telegram et portefeuille fictif. 100 % gratuit.

**Statut : démo** (`demo.html`, données fictives), en attente de validation avant le développement du vrai projet.

Le bot ne passe aucun ordre : il surveille, analyse, estime des probabilités et alerte. Ceci n'est pas un conseil en investissement.
